# position map derivation

artifact: position_map.tsv (sticker to name, both orbits, with letter, face, row, col, piece id) and position_map_inverse.tsv (name to sticker). generated by probe_sim.c build_names() from the repo's own geometry at HEAD 208976b, objects built with `make BUILDDIR=pgrg pgrg/obj/src/engine/cube.o pgrg/obj/src/engine/notation.o pgrg/obj/src/gen/targets.o`, probe compiled against those objects. run: `./pgrg/probe_sim.exe playground/ref_ground/rows.tsv playground/ref_ground`.

derivation, all arithmetic from src/engine/cube.c ct_frames and src/gen/targets.c grids:

1. our sticker index = face*4 + pos with face order U L F R B D = 0..5 (src/engine/cube.h:15). corner pos from ct_corner_grid: 0=(0,0), 1=(0,2), 2=(2,2), 3=(2,0), clockwise on the face grid from (0,0). edge pos from ct_edge_grid: 0=(0,1), 1=(1,2), 2=(2,1), 3=(1,0), clockwise from the top edge.
2. for each sticker, probe_sim calls ct_sticker_cell to get (face,row,col) and ct_sticker_world(3, face,row,col) for the world center. face frame directions (ct_frames, src/engine/cube.c:5-12): U row runs toward +Z (F) and col toward +X (R), L row toward -Y (U) and col toward +Z (F), F row toward -Y (U) and col toward +X (R), R row toward -Y (U) and col toward -Z (B), B row toward -Y (U) and col toward -X (L), D row toward -Z (B) and col toward +X (R).
3. the world center signs name the piece: e.g. corner sticker face U row 2 col 2 gives center (2,2,2) = the UFR corner, so corner sticker 2 is the U sticker of UFR. edge sticker face U row 2 col 1 gives center (0,2,2) = UF edge, sticker 26 is the U sticker of UF.
4. name = the sticker's own face letter first, then the other faces of the piece in axis priority U/D before F/B before R/L (matches the blddb convention, see blddb_semantics.md, verified 48/48 against tracer.py solved_333 tables).
5. letter = 'A' + pos within the orbit, which equals the repo's seeded speffz scheme (db/seeds/speffz.sql, seed rule 'A'+sticker in src/storage/repo_settings.c:281). spot pins: corner sticker 2 = UFR = letter C, edge sticker 2 (26 absolute) = UF = letter C, both matching playground/buffer_ufr/phase1_ripple.md and classic speffz (corner A=UBL B=UBR C=UFR D=UFL, edge A=UB B=UR C=UF D=UL).

piece column: ct_corner_piece_of / ct_edge_piece_of from src/gen/targets.c, used by the simulation checks for piece grouping.
